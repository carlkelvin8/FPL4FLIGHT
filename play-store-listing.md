## App Name

## Short Description (80 chars)
Digital flight planning, ICAO forms, pilot logbook & aviation tools for PH pilots

## Full Description (4000 chars max)
FPL4FLIGHT is the essential digital toolkit for Filipino pilots and aviation professionals. Manage your flights, fill out CAAP-standard forms, track your logbook hours, and access critical aviation resources — all from your phone.

✈️ FLIGHT MANAGEMENT
• Schedule and track flights with departure/arrival details
• View flight status (scheduled, active, completed)
• Full flight detail cards with route visualization

📋 ICAO-STANDARD FORMS
• CAAP Flight Plan (ATS 2019-1) — official format
• PNP Arrival & Pre-Flight Checklists
• Passenger Manifest
• Aircraft Flight Logbook
• Export to PDF, share via email, or generate QR codes

📖 PILOT LOGBOOK
• Log all flight hours: PIC, SIC, Dual, Night, IFR, Cross-Country
• Currency tracker (Day/Night/IFR per FAR 61.57)
• Export logbook to formatted PDF
• Import from CSV

🛫 AVIATION TOOLS
• E6B Flight Computer (TAS, wind correction, fuel)
• Weight & Balance Calculator
• NOTAM Viewer (real-time from aviationweather.gov)
• VFR/IFR Flight Planning with fuel endurance
• Navigation Log (waypoint-by-waypoint)
• AIP Reference (Philippine aeronautical publications)
• Duty & FRMS Tracker

🗺️ MAP & TRACKING
• Real-time GPS position with speed, altitude, heading
• Multiple map types (standard, satellite, hybrid)
• Position compass and flight data strip

💬 PILOT CHAT (PIREP)
• Real-time aviation chat rooms
• Channels: General, Flight Ops, Weather, ATC, Random
• Image sharing, reactions, replies, message search

🔐 SECURITY & SYNC
• Secure authentication with email or Google
• Biometric lock (fingerprint/face)
• Offline mode with automatic sync
• Cloud backup via Supabase
